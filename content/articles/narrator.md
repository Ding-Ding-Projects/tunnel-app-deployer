# Narrator

The narrator reads progress, results and notifications aloud with the voices installed on this computer. It is off until you turn it on in **Settings › Language and voice**.

## Voices

- **English voice** and **Cantonese voice** each list only the matching voices installed on this computer. **Choose automatically** picks the first English voice, and the first Hong Kong Cantonese voice.
- Under each picker, **In use** names the voice that will really speak. If no Cantonese voice is installed, it says so; install one from your operating system's speech settings.
- **Narrator speed** and **Narrator pitch** go from 0.5 to 2.

In bilingual mode, the English line is spoken first with the English voice and the Cantonese line next with the Cantonese voice. The same message is never repeated within four seconds.

## Not built yet

The narrator does not detect a running screen reader yet, so turn one of them off if you hear both.
