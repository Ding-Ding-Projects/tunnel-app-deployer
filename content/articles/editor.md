# Opening a project in an editor

Once a project is chosen, the Host screen shows three buttons, also in the project's context menu:

- **Open folder in VS Code** opens the project folder in Visual Studio Code. Shortcut: **Ctrl+Shift+E**.
- **Open file in default editor** opens the Dockerfile or Compose file in the app your system uses for it.
- **Show in file manager** opens the folder with the file selected.

The app looks for Visual Studio Code in the usual per-user and machine-wide locations, the Insiders edition and folders on your PATH, without running anything. If it is not found, that button is disabled and **Get VS Code** links to the official download page.

Only the project you chose can be opened this way.
