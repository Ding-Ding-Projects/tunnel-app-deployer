# Schedules

Change settings automatically at set times.

**Settings › Schedules** lists your schedules. Each one has a name, a start and end time, the values it sets (theme, motion, action sounds and focus) and a switch. Two examples ship turned off: **Evening** (dark theme and gentle motion from 18:00 to 07:00) and **Work hours** (focus from 09:00 to 17:00).

## How they apply

- Times use this computer's local time, so daylight-saving changes follow your system clock.
- A schedule applies once, when its time window starts. If you change a setting by hand afterwards, your change stays until the next schedule starts.
- When windows overlap, the schedule higher in the list wins.
- A window that ends earlier than it starts, such as 18:00 to 07:00, runs overnight.
- Each scheduled change is recorded in settings history with the schedule's name.
