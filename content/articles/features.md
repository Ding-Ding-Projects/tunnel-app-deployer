# The feature inventory

The **Features** screen and the website list every feature this project aims to carry, with an honest status.

| Status | Meaning |
| --- | --- |
| Built | Works in this release. |
| Partly built | Some of it works; the note says what is missing. |
| Not built yet | Planned, not available. |
| Does not apply | Not relevant to this app; the note says why. |

The list in the app and on the website come from the same file, `content/features.json`, so they always agree. Built and partly built items link to their article. Search the list, filter by status, and press a card to open its article.
