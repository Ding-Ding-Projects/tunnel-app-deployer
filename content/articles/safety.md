# Two-key confirmation

Actions that cannot be undone ask for two separate keys and a slide before they run.

## Which actions use it

- **Stop sharing** while a link is live.
- **Clear session history** and **Remove** selected sessions.
- **Reset all settings** and **Clear all** notifications.

## How it works

1. The confirmation names the exact action and what it affects.
2. Turn **Key 1** and **Key 2**. Each is its own button, so one stray press is never enough.
3. The slider unlocks. Drag it all the way to the end, or use the arrow keys, to confirm.
4. **Emergency exit** or **Escape** closes it at any time, and focus returns to the button you started from.

Nothing happens until both keys are on and the slider reaches the end. With motion turned off, the key and slider states still change colour and text, so the confirmation stays clear.
