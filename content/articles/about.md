# Version, changelog and price

## Version and build time

The top bar shows the running version and the time it was built, with seconds and the time zone. Both come from the build record packaged with the app. A copy run from source has no build record and says **Build time unavailable** instead of guessing.

## Changelog

**Settings › About › Changelog** lists every release with its date, changes and commit. Filter by a date range or search with the regex builder.

## Price

The app is free. There is no paid tier, no advertising and no upgrade prompt.
