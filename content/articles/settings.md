# Settings

Everything is saved on this computer, explained in place, searchable, and resettable group by group.

## Groups

- **Appearance**: theme and accent colour.
- **Motion and sound**: motion level, action sounds and volume.
- **Language and voice**: language mode, playfulness sliders and dialog emoji.
- **Focus modes**: five separate switches.
- **Accessibility**: text size, density and command palette size.
- **Notifications**: how long notifications stay.
- **Data and history**: settings history with restore, exports, and resets.
- **About**: version and build time, changelog, the app's name and the welcome tour.

Each setting has an **info** button that explains what it changes. The search at the top finds settings by name or description, with the regex builder beside it.

## Renaming the app

**About › App name** changes the name shown in the window title and the header. **Restore original name** puts it back. Data folders, the package and the update source keep the original name.

## Resetting

**Reset this group** resets one group. **Reset all settings…** resets everything after a two-key confirmation. Old values stay in settings history.
